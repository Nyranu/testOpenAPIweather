# SnakeLevelsGame

Учебный минималистичный проект игры «Змейка» на Python и Pygame с тремя уровнями сложности.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Управление

- Стрелка вверх — движение вверх
- Стрелка вниз — движение вниз
- Стрелка влево — движение влево
- Стрелка вправо — движение вправо
- Мгновенный разворот в противоположную сторону запрещён

## Уровни

- **Уровень 1:** маленькое поле, низкая скорость, цель 3
- **Уровень 2:** поле больше, скорость выше, цель 5
- **Уровень 3:** самое большое поле, самая высокая скорость, цель 8

## Особенности

- Внутренних препятствий нет
- На поле есть полупрозрачная клеточная сетка
- Победа на уровне наступает при достижении целевого счёта

## Игровой цикл

1. В главном меню выберите уровень 1, 2 или 3.
2. На игровом экране нажмите кнопку **«Начать»**.
3. Собирайте еду, избегайте выхода за границу и столкновения с собой.
4. При достижении цели показывается экран **«Уровень пройден»**.
5. После победы или проигрыша используйте **«В меню»** или **«Повторить»**.
