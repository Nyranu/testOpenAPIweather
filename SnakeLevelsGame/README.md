# SnakeLevelsGame

Учебный минималистичный проект игры «Змейка» на Python и Pygame с тремя уровнями сложности.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Управление

- Стрелка вверх — движение вверх
- Стрелка вниз — движение вниз
- Стрелка влево — движение влево
- Стрелка вправо — движение вправо
- Мгновенный разворот в противоположную сторону запрещён

## Уровни

- **Уровень 1:** низкая скорость, большое поле, без препятствий
- **Уровень 2:** скорость выше, 3 препятствия
- **Уровень 3:** самая высокая скорость, больше препятствий и меньше свободная зона

## Игровой цикл

1. В главном меню выберите уровень 1, 2 или 3.
2. На игровом экране нажмите кнопку **«Начать»**.
3. Собирайте еду, избегайте стен, препятствий и столкновения с собой.
4. После проигрыша используйте **«В меню»** или **«Повторить»**.
