# Project to PDF (Tkinter)

Простое учебное desktop-приложение на Python + Tkinter.

Приложение позволяет:
- выбрать папку с проектом;
- собрать текстовые файлы в единый PDF-отчёт;
- сохранить PDF в `output/`;
- просматривать PDF прямо в окне приложения;
- листать страницы PDF;
- приближать и отдалять PDF (zoom) с прокруткой по вертикали и горизонтали.

> Примечание: предупреждения про `pymupdf.exe` и `PATH` можно игнорировать — приложение использует `import fitz`.

## Требования

- Python 3.10+

## Установка и запуск

```bash
cd project_to_pdf_tkinter
python -m venv .venv
pip install -r requirements.txt
python main.py
```

1. Нажмите **«Выбрать папку»** и выберите каталог проекта.
2. Нажмите **«Конвертировать в PDF»**.
3. Просматривайте PDF в центральной области окна.
4. Используйте кнопки **«Предыдущая страница»** и **«Следующая страница»** для навигации.
