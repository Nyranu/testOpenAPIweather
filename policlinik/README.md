# Поликлиника (консольный учебный проект)

Простой консольный Python-проект для учета клиентов поликлиники и записи к врачу.

## Что умеет

- регистрация клиентов;
- авторизация пользователей;
- роли: `admin`, `doctor`, `client`;
- запись клиента к врачу на свободный слот;
- просмотр записей по ролям;
- добавление врачей и слотов администратором.

## Технологии

- Python
- SQLAlchemy
- dataclasses
- MySQL (основной вариант)
- SQLite fallback (по умолчанию)

## Установка и запуск

```bash
cd policlinik
pip install -r requirements.txt
python main.py
```

## Режим SQLite (по умолчанию)

Если переменная `DATABASE_URL` не задана, используется локальная база:

- `sqlite:///policlinik.db`

Файл `policlinik.db` создается автоматически и хранит данные между запусками.

## Подключение MySQL через DATABASE_URL

Если нужно использовать MySQL, задайте переменную окружения перед запуском.

Пример:

```bash
export DATABASE_URL="mysql+pymysql://user:password@localhost:3306/policlinik"
python main.py
```

## Начальные данные

При первом запуске автоматически создаются:

- администратор: `admin/admin`;
- врачи и их логины:
  - Иван Петров — Терапевт (`doctor1/doctor1`)
  - Ольга Смирнова — Хирург (`doctor2/doctor2`)
  - Сергей Иванов — Невролог (`doctor3/doctor3`)
- стартовые слоты на даты:
  - 2026-05-23 10:00
  - 2026-05-23 11:00
  - 2026-05-24 10:00
  - 2026-05-24 11:00

Повторный запуск не дублирует эти данные.

## Роли и доступ

### Клиент

- просмотр своего профиля;
- запись к врачу;
- просмотр своих записей.

### Врач

- после входа врач автоматически связывается со своим профилем по `user_id`;
- врач видит только записи к себе;
- врач не может смотреть записи других врачей.

### Администратор

- просмотр всех клиентов;
- просмотр всех записей;
- просмотр всех врачей;
- добавление врача (ФИО, специализация, логин, пароль);
- добавление слотов.

## Важное замечание про пароли

В проекте пароли хранятся в открытом виде, потому что это учебный пример.
Для реальных систем обязательно использовать хеширование паролей (например, `bcrypt`/`argon2`).

## Короткий пример сценария

1. Запустить `python main.py`.
2. Зарегистрироваться как клиент.
3. Войти под новым логином и записаться к врачу.
4. Войти как `doctor1/doctor1` и посмотреть только свои записи.
5. Войти как `admin/admin` и посмотреть все записи.
6. Добавить нового врача через меню администратора.
